# Hesappcepte

A personal and shared finance management application. The backend is under active development; a React frontend is planned.

## Tech Stack

- **Backend:** Java 21, Spring Boot, Spring Security (JWT), Spring Data JPA / Hibernate
- **Database:** PostgreSQL, Flyway
- **Development:** Maven, Docker, Postman
- **Frontend:** React (planned)

## Implemented Features

- User registration and JWT-based authentication
- Personal account creation, listing, updates, archiving, and reactivation
- Finance area creation, listing, details, renaming, archiving, and restoration
- Membership-based access control with OWNER permissions for finance area management
- Request validation and structured API error responses

## In Progress / Planned

- Area member management (listing, invitations/addition, roles, removal)
- Income and expense tracking, reporting, and dashboards
- Automated tests and React frontend

## Status

Work in progress. Core backend endpoints have been manually tested with Postman; automated test coverage is planned.
